# Phòng khám ngoại trú

Mở trang: https://doctor-gau-1607.github.io/pk-ngoai-tru/ — vào thẳng phòng khám với một bệnh nhân rút ngẫu nhiên.

- `index.html`: app (nguồn chính, sửa trực tiếp).
- `muc_luc.json`: mục lục ca (mã, chuyên khoa, repo chứa ca).
- `kho/`: danh mục khám, cận lâm sàng, media, trị số tham chiếu, viết tắt.
- Ca nằm ở `pk-ngoai-tru-ca-1` … `-ca-4`; âm thanh, hình ở `pk-ngoai-tru-media-1` … `-media-3`.
- Báo lỗi: nút ⚠ trong app mở phiếu (issue) có nhãn `bao-loi`; tác vụ viết ca đọc và sửa.
